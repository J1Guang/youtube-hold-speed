# v1.0.0 验证记录

日期：2026-09-30。

## 本地结果

- 环境：Windows、Node.js 24.14.1、Google Chrome 154.0.8037.57、Playwright 1.63.0。
- Chrome 在独立临时配置中通过 DevTools `Extensions.loadUnpacked` 安装真实扩展，内容脚本按 Manifest 配置自动注入隔离环境。
- `npm run check`：通过。
- `npm test`：**41 项通过**，全套运行耗时约 20 秒。
- `npm run package`：通过；ZIP 条目和完整性验证通过，安装包仅含 Manifest、内容脚本及 4 个图标。

## 验证边界

集成测试使用本地生成的真实媒体和模拟播放器的键盘处理函数，不使用 YouTube 在线播放器。可见性事件在扩展隔离环境中模拟，因为无头浏览器的页面保持可见。

本地访问 `www.youtube.com` 时连接被重置，访问 `www.youtube-nocookie.com` 时超时，因此 **YouTube 在线实播及其原生短按快进处理尚未验证**。发布包保留这一限制；请按 README 的手动验收步骤在能访问 YouTube 的环境中检查。测试通过不能保证 YouTube 后续页面更新或其他扩展组合下的兼容性。

GitHub Actions 的执行结果以仓库 Actions 页面为准。
